# c-send-library

c-send PWAから利用するAPI設定・プロンプト・テンプレートの公開ライブラリです。

## 公開

`master`へのpush、またはGitHub Actionsの`Deploy c-send library to Pages`を実行すると、GitHub Pagesへ公開します。

公開サイトでは`catalog.json`を生成し、API設定と日本語・英語のデータセットを配布します。各データセットのタグを集計してタグチップを表示し、用途別に絞り込めます。

公開URL: https://narusue.github.io/c-send-library/
